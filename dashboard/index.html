What is proven, and what is not

  • Proven in simulation: physics against hand calculations, an independent model, energy conservation, step-size convergence, fail-safe behaviour and controller stability, all in an automatic test suite ().
  • Assumed: many vehicle parameters are engineering estimates pending RDSO data; the model is vertical only; power electronics are average models; the hot-axle model is illustrative.
  • Next: the bench prototype is designed (hardware ratings, bench model, C firmware checked against MATLAB, test plan); build and test it (Gate B), then an instrumented field run.
